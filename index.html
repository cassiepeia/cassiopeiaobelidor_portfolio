HIRAYA BANK — Mobile App User Flow

Live Wireframe Simulation 8 Screen Journey
01 Empathize 15 User Interviews

03 Ideate e-KYC Flows

The Challenge & Problem:

Users frequently abandoned traditional banking registration because of cumbersome manual identity validation and disjointed authentication feedback loops.

The Solution:

A streamlined 3-step registration flow integrating real-time camera alignment guides for ID scanning, haptic feedback, and a personalized visual dashboard showing instant balance visibility.
